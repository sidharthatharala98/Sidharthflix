# SidharthaFlix Portfolio

Netflix-inspired, responsive portfolio built with React + Vite.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL Vite prints.

## Customize before publishing
- Confirm the email address in `src/App.jsx`. It currently uses the address supplied in chat.
- Review all skill labels and keep only skills you can confidently discuss.
- Add real GitHub/demo URLs and technical details to project cards where available.
- Experience is intentionally factual. No unverified internships or employment at third-party startups are invented.
- To deploy, run `npm run build` and publish the `dist` folder to Vercel or Netlify.
